Features

Wiper seal DS-055 is a double acting rod wiper for integral housing.


Composition

Seal Profile type DS055-U DS055-N DS055-F
Material Polyurethane Nitrile Butadiene Rubber (NBR) Fluoro Carbon Rubber(FPM)
Code PUAB94 NBR90 FPM80
Properties Application
Easy snap in installation. Presses, fork lift & material handling equipments.
Very good wiping action. Injection moulding machines.
Wiper can be used for a broad temperature range. Standard cylinders.
