Features

SS001 is a single acting U cup type seal with O ring energizer used for both piston and rod seal.

Composition

Component Material Code
Main Seal Polyurethane PUAB92
Energizer O ring NBR NBR70
Properties Application
High resistance to abrasion. Mobile Hydraulics.
Easy installation. Machine tools.
Second seal ring take load in high pressure conditions. Agricultural equipment.
Standard cylinders.
Injection moulding machines.

General Technical Data

Working Pressure (max.) 400 Bar
Temperature range -20 to +100°C
Surface Speed (max.) 0.5 m/s
